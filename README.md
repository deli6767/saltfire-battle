# Saltfire Battle

Mobile-friendly boat combat game with detailed water physics.

## Play

Open `index.html` in a browser or enable GitHub Pages for this repo.

**Controls**
- Desktop: WASD / Arrows to move, Space to shoot
- Mobile: Virtual joystick + FIRE button

Dodge enemy boats, shoot them down, survive as long as you can.

Features:
- Multi-wave ocean with realistic bobbing
- Loading screen
- Touch controls
- Combat with AI enemies
- Health and score
