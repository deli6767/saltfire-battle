# Saltfire Battle v2

Mobile-friendly boat combat game with improved realism.

## v2 Changes
- Procedural sky with golden hour sun and horizon
- Multi-layer waves + multi-point buoyancy so boats actually tilt and bob
- Rock collision (you bounce off and take damage)
- Smarter AI (some patrol, some hunt you)
- Spray particles at high speed
- Better lighting and atmosphere

## Play
Open `index.html` in any browser (or enable GitHub Pages).

**Controls**
- Desktop: WASD / Arrows to drive, Space to shoot
- Mobile: Virtual joystick + FIRE button

Avoid the rocks. Shoot the aggressive boats. Don't get wrecked.
