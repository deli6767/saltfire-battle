# Saltfire Battle

Full mobile-friendly boat combat game.

This version (Claude-generated) includes:
- Procedural sky with sun sprite and drifting clouds
- Detailed ocean with foam vertex colors and multi-wave buoyancy
- Full particle system (spray, explosions, smoke, damage effects)
- AI fleet with allies and hostiles
- Lock-on targeting + lead indicator
- Minimap
- Boost, proper velocity physics, rock/island collision
- Overlay HUD with targeting brackets, distance, health bars
- Manual look / aim controls

## Play
Replace `index.html` with the full game file, then open it or enable GitHub Pages.

**Controls**
- Desktop: W/S throttle, A/D steer, SHIFT boost, SPACE fire, E cycle lock, Q clear lock, drag to look
- Mobile: Joystick, FIRE, LOCK, BOOST buttons

Survive the hostiles.
